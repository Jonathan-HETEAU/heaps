# h3d.mat.PbrBlend

**enum abstract** · package [`h3d.mat`](README.md) · module `h3d.mat.PbrMaterial` · source [`h3d/mat/PbrMaterial.hx`](../../../../../h3d/mat/PbrMaterial.hx)

The blend mode of a `PbrMaterial` (see `h3d.mat.BlendMode`).

Underlying type: `String`

## Values

| Name | Value | Description |
|---|---|---|
| `None` | `"None"` | No blending: opaque. |
| `Alpha` | `"Alpha"` | Alpha blending. |
| `Add` | `"Add"` | Additive blending. |
| `AlphaAdd` | `"AlphaAdd"` | Additive blending, multiplied by the alpha. |
| `Multiply` | `"Multiply"` | Multiplies the destination color. |
| `AlphaMultiply` | `"AlphaMultiply"` | Multiplies the destination color, weighted by the alpha. |
