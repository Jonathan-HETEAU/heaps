# hxd.Res

**class** · package [`hxd`](README.md) · source [`hxd/Res.hx`](../../../../hxd/Res.hx)

The access point to the resources (the files of the `res` directory). Its fields are generated by a macro from the
resource files: `hxd.Res.my.image` is the resource `res/my/image.png`.

Initialize the resource loader once, before accessing resources:

```haxe
hxd.Res.initEmbed(); // resources embedded in the binary
var tile = hxd.Res.hero.toTile();
```

### load

### initEmbed

```haxe
static function initEmbed(?options:Null<hxd.res.EmbedOptions>):Dynamic
```

Initializes the loader with the resources embedded in the binary (all platforms).

### initLocal

```haxe
static function initLocal(?configuration:Dynamic):Dynamic
```

Initializes the loader with the files of the resources directory on disk (desktop and Node.js), which allows hot reloading.
The directory is `res` or the `-D resourcesPath=...` value.
- **param** `configuration` The configuration used to convert the resources (see `hxd.fs.Convert`).

### initPak

```haxe
static function initPak(?file:Dynamic):Dynamic
```

Initializes the loader with resources packed in `.pak` files (see `hxd.fmt.pak`).
