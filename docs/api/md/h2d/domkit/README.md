# Package `h2d.domkit`

[← API index](../../README.md)

| Type | Kind | Summary |
|---|---|---|
| [`BitmapComp`](BitmapComp.md) | class | The `<bitmap>` domkit component (`h2d.Bitmap`): adds the tile (`src`, with its grid position and flipping) and the size. |
| [`CustomParser`](CustomParser.md) | class | The parser of the CSS values of the h2d components (tiles, fonts, filters, alignments...). |
| [`DrawableComp`](DrawableComp.md) | class | The `<drawable>` domkit component (`h2d.Drawable`): adds the tint color, smoothing, color adjustment and tile wrapping. |
| [`FlowBg`](FlowBg.md) | typedef | The value of the `background` CSS property of a flow: a tile with its scale grid borders, and its color for transitions. |
| [`FlowComp`](FlowComp.md) | class | The `<flow>` domkit component (`h2d.Flow`): adds the size constraints, background, layout, padding, spacing, alignment and overflow. |
| [`HtmlTextComp`](HtmlTextComp.md) | class | The `<html-text>` domkit component (`h2d.HtmlText`): adds the white space condensing and the tag definitions. |
| [`InputComp`](InputComp.md) | class | The `<input>` domkit component (`h2d.TextInput`): adds the width, the cursor and selection tiles, the edition, background color and multiline options. |
| [`MaskComp`](MaskComp.md) | class | The `<mask>` domkit component (`h2d.Mask`): adds the mask width and height. |
| [`Object`](Object.md) | interface | Implement this interface to declare an `h2d.Object` subclass as a domkit component, with its markup and CSS properties. |
| [`ObjectComp`](ObjectComp.md) | class | The `<object>` domkit component (`h2d.Object`): position, scale, rotation, alpha, filter, and the flow properties of the element in its parent flow (margin, align, position, offset, min size, auto size). |
| [`ScaleGridComp`](ScaleGridComp.md) | class | The `<scale-grid>` domkit component (`h2d.ScaleGrid`): adds the borders, their scale and tiling, and the size. |
| [`SourceFile`](SourceFile.md) | typedef | A loaded CSS source file. |
| [`Style`](Style.md) | class | The CSS style sheets applied to domkit components. |
| [`TextComp`](TextComp.md) | class | The `<text>` domkit component (`h2d.Text`): adds the font, color, spacing, line breaking, alignment and shadow. |
| [`VideoComp`](VideoComp.md) | class | The `<video>` domkit component (`h2d.Video`): adds the video resource (`src`) and looping. |
